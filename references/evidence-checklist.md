# 证据核验清单

## 各类买家的有效来源

| 买家类别 | 可用证据来源 |
| --- | --- |
| 高校与科研机构 | 高校 `.edu.cn` 域名下的技术转移或成果转化页面；专利主管机关的公开记录；注明日期、能直接证实事件的机构官方新闻。 |
| 金融与保险公司 | 监管机构披露或备案文件；机构官方产品页面；注明日期、明确说明产品发布或业务扩展的官方新闻稿。 |
| 综合性律所 | 律所官方招聘页面；官方 IP 业务设立公告；律师协会的招聘或执业记录。需另核实该所是否已有成熟 IP 业务。 |

## 无效来源（三类买家均适用）

- 搜索结果摘要：不能代替打开原页面核验。
- 无日期的通用首页：无法证明具体事件和时间。
- 没有指向具体事件的直接链接的泛泛新闻。
- 缺少一手来源佐证的 LinkedIn 帖子。

## 核验步骤

1. 打开候选线索背后的原始页面，确认链接直接支持所述事件。
2. 记录具体事件、事件发生日期和页面发布日期；未注明的日期标为未知。
3. 将可核实的事实与知识产权服务切入点分开，后者明确标为**推断**。
4. 合并同一事件的重复报道，同一机构不要因转载被重复计为多条线索。
